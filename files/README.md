# Generated Project I.G.I. browser build files

This folder is reserved for generated browser-engine output.

After a successful GitHub Actions build, download the `Project-IGI-browser-build` artifact from the Actions run. It contains `recomp.js`, the matching `recomp.wasm`, and any companion runtime files emitted by Emscripten.

The proprietary game executable and game data are intentionally not committed to this public repository. The generated engine output is kept as a downloadable Actions artifact rather than committing large build binaries to the source tree.
